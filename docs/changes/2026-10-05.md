## 修复：桌面/Startup 快捷方式编码乱码（图标消失 + 开机自启失效）

- 现象：用户反馈桌面 Token Details 图标变空白。排查发现两个 lnk 均损坏：
  - 桌面 `Token Details.lnk`：target 仍指向旧 Python 版 `TokenDetails.exe`（P5 声称的"换装 native"没真正落到桌面），IconLocation 存的是乱码路径 `C:\Users\鏈╘Desktop\椤圭洰2608\...\TokenDetailsNative.exe` → 图标源定位不到，空白。
  - Startup `Token Details.lnk`：target/icon/wd **三字段全乱码** → 开机自启实际完全失效（自 P5 起就是坏的）。
- 根因：P5 写快捷方式用 PowerShell 脚本，中文路径经 Git Bash heredoc→PowerShell 传递时编码错乱，写进的是被错误解码的字节序列；"回读验证"也在同一编码层，所以没发现（教训：跨进程/跨编码层写入后，验证必须在编码透明的层做）。
- 修复：python COM 直写（IShellLinkW + IPersistFile，进程内全程 Unicode）——target→`dist\TokenDetailsNative.exe`、icon→`dist\token_speed.ico`（仓库根 ico 复制到 dist，与 exe 同目录；两个 exe 都无 .rsrc 图标资源，独立 ico 最稳）、wd→`dist`。回读三字段逐一字符串比对全部相等；shell32.SHChangeNotify(SHCNE_ASSOCCHANGED) 刷新缓存后桌面图标恢复（蓝色圆形 ico + "Token Details" 标签，截图确认）。
- 验证：点桌面快捷方式 → 单实例互斥生效（进程仍是 29204，未起第二实例），target 路径有效。
- ⚠️ 仍未验证：真实重启后 Startup 自启（需下次重启观察一次）。
- 附带观察：连续高频测试（codex 多轮重建 + 880×1320 大位图渲染 + 活跃流式会话）下私有内存涨到 118MB，测试负载结束后观察是否回落。
