# 2026-10-01 ZCode Header Overlay

- `token_speed.py` 默认改为透明 overlay：按前台 ZCode 客户区右上角和 `h-12` Header 高度定位，随窗口移动、缩放、最大化、还原和 DPI 变化同步；ZCode 非前台、最小化或关闭时隐藏。
- 新增 `--standalone` 兼容模式保留原自由悬浮面板和把手拖动。
- 多窗口时优先前台 ZCode，否则按可见面积选择主窗口，避免把辅助窗口当成 Header 锚点。
- 验证：`python -m py_compile token_speed.py`、`python token_speed.py --self-check` 通过。
