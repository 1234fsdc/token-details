# 2026-10-01 ZCode Header Overlay

- `token_speed.py` 默认启动拆为三种面板：`Token Details` 简略面板、`Token Details 详情` 详情面板、`Token Details ZCode` 当前会话 overlay。
- ZCode overlay 通过 UI Automation 读取 Header 当前任务标题和模型，映射 SQLite `session_id` 后按当前 session + model 聚合；切换会话或模型不会沿用旧速度。
- 无新模型有效记录时显示 `—`，不使用全局最近模型速度兜底。
- `--standalone` 保留原自由悬浮面板和把手拖动。
- 未修改 `C:\APP\ZCode`、ZCode 配置、数据库或安装包。
- 修复 PowerShell UI Automation 中文输出按系统编码读取的问题，避免中文 session 标题解码失败后把当前会话清空；同时移除重复的 overlay 样式定义。
- 修复 ZCode overlay 外观和定位：移除深色不透明胶囊背景、边框和阴影；通过 UI Automation 读取“选择打开方式”按钮的真实 bounds，将速度文字放到该按钮左侧 8px；锚点缺失时隐藏 overlay，不再错误落到 Header 下方或右侧。
- 修复 overlay 显示后短暂成为前台导致同步线程立即隐藏的问题：ZCode 主窗口或 overlay 自身处于前台时都保持定位；当前实例实测外框 `(2000,26)-(2356,90)`，目标按钮左边为 `2372`，200% DPI 下间距为 8 CSS px。
