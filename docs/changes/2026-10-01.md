# 2026-10-01 ZCode Header Overlay

- `token_speed.py` 默认启动拆为三种面板：`Token Details` 简略面板、`Token Details 详情` 详情面板、`Token Details ZCode` 当前会话 overlay。
- ZCode overlay 通过 UI Automation 读取 Header 当前任务标题和模型，映射 SQLite `session_id` 后按当前 session + model 聚合；切换会话或模型不会沿用旧速度。
- 无新模型有效记录时显示 `—`，不使用全局最近模型速度兜底。
- `--standalone` 保留原自由悬浮面板和把手拖动。
- 未修改 `C:\APP\ZCode`、ZCode 配置、数据库或安装包。
- 修复 PowerShell UI Automation 中文输出按系统编码读取的问题，避免中文 session 标题解码失败后把当前会话清空；同时移除重复的 overlay 样式定义。
- 修复 ZCode overlay 外观和定位：移除深色不透明胶囊背景、边框和阴影；通过 UI Automation 读取“选择打开方式”按钮的真实 bounds，将速度文字放到该按钮左侧 8px；锚点缺失时隐藏 overlay，不再错误落到 Header 下方或右侧。
- 修复 overlay 显示后短暂成为前台导致同步线程立即隐藏的问题：ZCode 主窗口或 overlay 自身处于前台时都保持定位；当前实例实测外框 `(2000,26)-(2356,90)`，目标按钮左边为 `2372`，200% DPI 下间距为 8 CSS px。
- 根治 overlay“有时候有、有时候没有”（weberr.log 实测 `uia-context` TimeoutExpired 成串出现，每轮超时返回全空 → 锚点被清空 → 同步循环隐藏）：UIA 本轮健康（anchor 非空）才更新锚点/标题/模型，超时或异常时整体沿用上次健康值（`uia_last`）；同步循环另存按钮相对客户区右缘/顶缘的偏移（`anchor_rel`），UIA 失败期按当前客户区推出按钮位置，窗口移动/改宽也不跑偏。
- 空会话/当前模型无已完成请求时显示 `0 t/s`（用户要求显示零而不是隐藏），tooltip 标注“当前会话暂无已完成的请求”；self-check 增加 `textContent="0"` 断言。
- 每秒一次的 UIA 探测改用 `subprocess.CREATE_NO_WINDOW`：`-WindowStyle Hidden` 要等 PowerShell 启动后才生效，用户实测每秒闪终端黑框；`CREATE_NO_WINDOW` 从进程创建起就不分配控制台。
- 分层窗口 alpha 从 255 回调 232：WebView2 + `LWA_ALPHA` 255 实测会出现整窗内容不合成（透明方案 memory 记录的失败模式）。
- 配色适配 ZCode 浅色 Header：深色墨水 `#11151a` 主文字、灰 `#6b7280` 单位/空态，fast/mid/slow 改深绿/深琥珀/深红，移除黑描边（此前深底浅字+黑影在浅底上显脏）。
- 截图验收（`C:/Users/Public/capture_overlay.py`，ZCode 拉前台后抓屏）：两张间隔 6 秒均稳定显示速度（46.4 → 44.2 实时更新），位置贴“选择打开方式”左侧；热更新后新配色生效。
- ⚠️ 未验证：空会话 `0 t/s` 仅由 self-check 断言与 JS 分支覆盖，未在真实空会话下截图；UIA 超时期间的表现靠粘滞逻辑与日志推断，无法在截图里复现超时窗口。
- 用户反馈“只要文字、不要任何底色”：overlay 宿主从 pywebview/WebView2 窗口改为**原生层叠窗口**（专用线程注册 `TokenDetailsOverlay` 类并自建消息泵），PIL 把速度文字渲染成每像素 alpha 位图经 `UpdateLayeredWindow` 合成——窗口内除文字外零像素。像素探针实测 overlay 内部与紧邻 Header 完全一致（248 vs 248），不再透出 WinForms 宿主的 #F0F0F0 底色。
- 移除 `ZCODE_HTML`/`zw` WebView2 窗口与 LWA alpha 方案；速度数据经 `overlay_payload` 共享给同步线程（变化才重绘）。教训：该窗口必须自己泵消息，跨线程 ShowWindow/ULW 依赖宿主线程消息循环，挂主线程会被 webview 主循环饿死（实测 SetWindowPos 卡死）。
- 顺带收益：少一个 WebView2 渲染进程；tooltip 随浏览器一并移除（点击穿透窗口无法承载悬停提示）。
- 用户反馈颜色/位置微调：数值统一 Header 墨水色 `#11151a`（不再按速度红/黄/绿分档），单位灰 `#6b7280`；与“选择打开方式”按钮间距 8→40 CSS px（`OVERLAY_GAP`）。
- 最终截图验收：`40.7 t/s` 墨水色浮于 Header、无底色、距按钮 40 CSS px，6 秒间隔两张数值实时更新且位置不变；空会话 0 t/s、UIA 超时粘滞、CREATE_NO_WINDOW 均已生效。
